新增离线回归覆盖有限动作协议、API 异常、模型与设备闭环、动作独立定位、取消／过期观察、执行模式隔离和原路线验证。`backend/test_autoglm_runtime.py` 的运行时回归包含模式冻结、显式重查换模式、无密钥零 GUI、API 失败无 rules 回退、地点选择恢复、原验证器 PARTIAL、过期事件与设备互斥、重启不重放等；这些使用替身，不代表云端 AutoGLM 或真实手机成功。完整自动化命令为 `.venv/bin/python -m pytest backend -q`，最终数量与实际运行条件须以本轮交付记录为准。

真实 AutoGLM 验收需要独立可用的 API Key、已授权且解锁的手机、小银无障碍服务和可查询的高德。条件不足时仍可完成代码与离线回归，但不生成真实成功结论。若具备条件，按专用说明用公开地点启动一次新查询，并逐项记录 `transit_executor`、真实 API 调用、实际动作／前后观察、最终分类与耗时；同环境 rules 对照也必须作为独立查询保存。

2026-11-14 后续已配置独立 AutoGLM 密钥并启用 Demo 无障碍，后端实际使用 `autoglm`。独立接口探针真实调用成功，`autoglm-phone` 返回 Launch，API 耗时 **3.867 秒**，探针未执行手机动作。完整配置和限制见 [AutoGLM 说明](AUTOGLM_TRANSIT.md)。
